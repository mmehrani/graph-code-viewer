Trial version — this is not the complete visualisation of all graph codes. This page carries only a sample of the dataset: at most two codes per (n, k, d, degeneracy) category — 41 codes in 21 categories — chosen, where the category spans more than one, from different local-Clifford classes.
  • Left out entirely (too large to host): general stabilizer n = 9, CSS n = 12 and n = 13 (2.5 GB, 30 MB and 1.7 GB).
  • The Full dataset counts in the search hints, and the LC-class numbers, are for the complete dataset — not for the handful of codes loaded here, so most searches will return far fewer results than the hint announces.
  • Line numbers on the result cards are lines of these demo files. The line of each sample in the full dataset is in demo_manifest.json.
  • The complete dataset will be released with the paper. If you already have a copy, press Open dataset folder… below and the viewer will use it instead.
